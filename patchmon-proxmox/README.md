# PatchMon Proxmox Auto-Deployment

Öffentliche Dateien für die automatische PatchMon-Installation auf Proxmox-Gästen.

Unterstützt:
- Linux-LXC
- Linux-VMs
- Windows-VMs
- FreeBSD/OPNsense-VMs

Die VM-Ausführung verwendet den QEMU Guest Agent. Zugangsdaten werden ausschließlich lokal auf dem Proxmox-Host gespeichert und nicht in dieses Repository geschrieben.
