# Installation

Die vollständige Installation erfolgt aus dem öffentlichen Repository. Klonen Sie das Repository nach /opt, wechseln Sie in pve-config-backup und führen Sie install.sh als root aus. Danach kann die Konfiguration mit /usr/local/sbin/pve-config-backup.sh --check geprüft und der Dienst pve-config-backup.service testweise gestartet werden.
